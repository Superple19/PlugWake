## Modifications

The downloaded PNG assets are modified for shortcut use:

- exported as 256x256 PNG files for Linux desktop entries
- exported as 256x256 ICO files for Windows shortcuts
- placed on a circular background
- normal icons use a white background with a light gray border
- `hard-reboot` uses a red background with a light red border
