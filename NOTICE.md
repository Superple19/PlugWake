# Notices

This project includes shortcut icons derived from SVG Repo assets.

- Remote Explorer icon: https://www.svgrepo.com/svg/361286/remote-explorer
- Server Off icon: https://www.svgrepo.com/svg/389398/server-off

Both source pages list the assets as CC0 License at the time they were added.

The project modifies the downloaded PNG assets by adding a white circular background and exporting them as `.ico` files.
